# CRUD App

A basic full-stack CRUD application with separate frontend and backend folders. This project demonstrates how data flows between a client and server and how basic create, read, update, and delete operations are handled.

## Structure

```
.
├── back
└── front
```

* `back` → backend service (API and data handling)
* `front` → frontend interface

## What it does

* Create new entries
* View existing data
* Update entries
* Delete entries

## Running the project

Clone the repo:

```bash
git clone https://github.com/your-username/Crud-App.git
cd Crud-App
```

### Backend

```bash
cd back
npm install
npm start
```

### Frontend

```bash
cd front
npm install
npm start
```

## Notes

* Start the backend before the frontend
* If the frontend is not connecting, check the API URL in the frontend code
* `.env` files are not included

## Why this project

Built as a practice project to understand how a frontend interacts with a backend and how CRUD operations are implemented in a simple setup.
